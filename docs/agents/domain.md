# Domain Docs

Before exploring the project, read:

- `CONTEXT.md` at the project root when it exists.
- Relevant decisions under `docs/adr/`.

If these files don’t exist, proceed silently. The domain-modeling skill creates them when useful.

## File structure

This project uses the single-context layout:

```
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

Use the vocabulary defined in `CONTEXT.md`. If proposed work conflicts with an existing decision record, identify the conflict explicitly.
